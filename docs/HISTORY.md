## 加固记录

**资料质量检查健壮性与关系持久化（2026-10-27）**

- `analyzeCatalog()` 对不可信 JSON 逐字段类型检查后再归一化；一条坏记录不会让整份报告崩溃，
  也不改入参。
- 写路径只落盘**显式改动的字段**；未编辑作品整条原样写回；编辑器附带的未变化 `relations`
  不算修改；词表改名 / 合并只 patch 分类字段；删除作品只清理指向它的入边。
- 回归覆盖无关字段编辑、显式关系编辑、删除目标、词表合并，以及异常输入与只读性。

**原始 ID 安全与 Game 契约（2026-10-27）**

- 远程仓与本地存档共用 `findCatalogIdentityIssues()`：缺失 / 空白 / 首尾空白 / 非字符串 /
  重复 id 时，任何目录写入在提交 / 落盘前被拒绝，错误信息指出 `games[n]`；失败零提交、零写入。
- `analyzeCatalog()` 按 `types/game.ts` 补齐契约检查（必填 / 可选字段、枚举、时间戳格式）；
  时间戳只接受带时区的完整 ISO 8601 并校验真实日期。
- `check:data --strict` 与 `test:data-quality` 纳入 `verify` 与部署 workflow；只对 error 失败。

**UI 测试纳入 CI（2026-10-27）**

- `test:ui:ci` 自动启动 / 清理 Vite，只认本次子进程的 ready 信号；
  `test:ui:ci-launcher` 回归端口占用时不得误连旧服务。
- 失败上传截图与 Vite 日志；部署因此被真实浏览器验证阻断。

**文档整理（2026-10-27）**

- README 收敛为入口页；细节拆到 `docs/`；计划书、设计冻结、逐阶段报告移出工作树（保留在 git 历史）。
